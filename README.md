# Aero-Simulations: OpenRocket Flight Analysis

An introductory rocket simulation project evaluating apogee, stability margin, and velocity profiles using OpenRocket.

## 🚀 Project Overview
This repository contains baseline 3D rocket model files, flight telemetry datasets, and flight profile plots generated from simulation runs.

## 📁 Repository Structure
* `designs/` - OpenRocket design file (`.ork`).
* `telemetry/` - Exported flight data (`.csv`) and flight performance graphs (`.png`).

## 📊 Key Results
* **Motor:** Baseline A8-3
* **Primary Focus:** Analyzing stability margins and peak altitude under standard atmospheric conditions.
